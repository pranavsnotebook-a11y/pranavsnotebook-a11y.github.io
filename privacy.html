This policy covers HTWFI Pipeline, the internal publishing tool of the How Tech Works From Inside YouTube channel.

Who uses it

Only the channel owner. The app is not offered to other people and does not collect data about viewers or anyone else.

What data it accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos, set titles, descriptions, tags, thumbnails and playlists, and read basic video statistics for the owner's own channel.

How the data is stored

The OAuth token is stored only on the owner's computer. No YouTube data is sold, shared with third parties, or used for advertising. Video statistics are kept locally to compare which videos perform best.

Google API Services

HTWFI Pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: contact the channel via its YouTube About page.
